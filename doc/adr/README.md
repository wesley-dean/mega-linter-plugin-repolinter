# Architecture Decisions

This directory contains accepted Architecture Decision Records for
`mega-linter-plugin-repolinter`.

## Current Decisions

### ADR-001: Support the Archived Repolinter 0.12.0 Release

The plugin intentionally integrates the final upstream Repolinter release,
0.12.0, after the TODO Group archived Repolinter on February 6, 2026.  The
descriptor pins that version, uses the documented `lint` CLI contract, and
supports project mode only.  Tests use deterministic local repositories rather
than cloning live external repositories, and this project does not assume
maintenance responsibility for upstream Repolinter.

See [ADR-001](ADR-001-support-archived-repolinter-0.12.0.md).

### ADR-002: Publish Versioned Repolinter Descriptor Release Assets

Normal consumers use versioned GitHub release assets rather than the mutable
`main` descriptor.  Each future release publishes the descriptor and a SHA-256
checksum after validating the exact generated bytes through MegaLinter.  The
publication job is separated from source-executing validation, and new releases
continue the repository's unprefixed semantic-version tag convention without
creating duplicate `vX.Y.Z` tags.

See [ADR-002](ADR-002-publish-versioned-descriptor-release-assets.md).
